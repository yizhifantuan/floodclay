# 19 地区卫星拍摄时间轴

每个地区一张图，按示例绘制 S1、S2、PS 三条灰色时间轴；蓝、绿、紫实心点表示实际拍摄日期，浅黄色阴影表示洪水期。没有红圈，也没有删除任何被红圈标记位置所代表的正常拍摄点。

## 文件与运行

- `figures/PNG/`：19 张高清单图，300 dpi，3600 × 1380 像素。
- `figures/SVG/`：同一批 19 张图的矢量格式，文字已转为路径，可缩放排版。
- `figures/19地区_总览预览.jpg`：全部地区的缩略预览。
- `plot_timelines.py`：完整 Python 绘图代码。
- `inputs/`：两份原始 Excel 的副本。
- `figures/绘图数据.csv`：所有实际绘制点，可逐个核对。
- `figures/地区核对.csv`：每个地区的洪水起止日期和三个平台的日期数。

在本文件所在文件夹打开终端，使用 Python 3.10 或以上版本运行：

```powershell
python -m pip install -r requirements.txt
python plot_timelines.py
```

如需指定原始文件或输出目录：

```powershell
python plot_timelines.py --dates "D:/路径/19地区_S1_S2_PlanetScope_拍摄日期汇总.xlsx" --events "D:/路径/洪涝事件.xlsx" --output "D:/路径/绘图结果" --dpi 300
```

若系统没有自动识别中文字体，可指定：

```powershell
python plot_timelines.py --font "C:/Windows/Fonts/msyh.ttc"
```

## 数据处理口径

1. 拍摄点仅来自《19地区_S1_S2_PlanetScope_拍摄日期汇总.xlsx》的“日期列表”页。每个地区、每个平台、每个日期为一个点，同一天不同平台分别绘制。脚本检查重复日期和缺少平台，不会静默删除异常记录。
2. 《洪涝事件.xlsx》的“洪涝发生时间”决定阴影范围，例如 `2017/03/14–05/02` 解析为 2017-03-14 至 2017-05-02，包含首尾日期。图上为了覆盖首尾日期点的中心位置，阴影在首尾各延伸半天。
3. 通过英文地区名匹配两个表，按日期汇总表中的地区顺序输出 19 张图。洪涝事件表末尾没有洪涝发生时间的零散地区备注不作为额外事件。
4. 日期汇总表“地区汇总”页存在 `#REF!` 公式错误，未使用这些单元格；图中日期数直接从有效的“日期列表”重新计数。原始文件不做修改。
5. 洪涝事件表中的三个“拍摄日期”列并不是完整日期列表，且其中部分日期不在日期汇总表中。本次仅用该表提供洪水期，不将那些单独列出的拍摄日期追加到图中。
6. 多数地区全部拍摄日期落在所给洪水期内，因此阴影可能覆盖全部拍摄点。这是输入数据的结果，没有人为缩短洪水期或添加洪水期外拍摄点。
7. 横轴为真实日期，每张图独立确定时间范围。年份写在轴标题中，刻度写为“月-日”。三种平台共用该地区的同一时间尺度。点表示拍摄日期，不表示影像张数。

样式参数在 Python 文件的 `COLORS` 和 `draw_region()` 中，可调整配色、点大小、图宽高、标题和字体。
